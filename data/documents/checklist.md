# Normal Procedures Checklist — C172S (from POH Section 4)

## Before Starting Engine
1. Preflight inspection — COMPLETE
2. Seats, belts, harnesses — ADJUST and LOCK
3. Fuel selector — BOTH
4. Avionics — OFF

## Engine Start
1. Mixture — RICH
2. Throttle — OPEN 1/4 in
3. Beacon — ON
4. Ignition — START (release to BOTH)
5. Oil pressure — CHECK within 30 seconds

## Before Takeoff
1. Flight controls — FREE and CORRECT
2. Engine run-up at 1800 RPM — magnetos, suction, instruments CHECK
3. Flaps — SET for takeoff (0–10 degrees)
4. Trim — SET for takeoff

## Cruise
1. Power — SET 2200–2700 RPM
2. Mixture — LEAN per EGT
3. Engine instruments — MONITOR

## Before Landing
1. Seats, belts — SECURE
2. Fuel selector — BOTH
3. Mixture — RICH
4. Flaps — AS REQUIRED (below 110 KIAS)
