# AFM Supplements — G-ECHO

This index lists the Aeroplane Flight Manual supplements applicable following equipment
changes. Each supplement amends the basic POH for the installed equipment.

## Supplement A — Garmin G1000 NXi Integrated Avionics
Covers PFD/MFD operation, GFC 700 autopilot limitations, and minimum-equipment notes for
IFR flight. Supersedes the legacy steam-gauge avionics supplement after the retrofit.

## Supplement B — GFC 700 Autopilot
Autopilot operating limitations: maximum and minimum engage speeds, approach mode
restrictions, and required preflight test.

## Supplement C — Mode S Transponder with ADS-B Out
Operating notes for the extended-squitter transponder and pilot actions on failure.

## Status
The avionics retrofit replaced the original vacuum-driven instruments; the legacy avionics
supplement is retained for historical reference but is no longer current.
